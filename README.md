# 公文白話通｜政府公文 AI 翻譯與行動指引

一個給**新住民、跨國青年與一般民眾**的公益工具：把充滿術語的政府公文、法規公告，貼進網頁後自動翻譯成**白話文與多國東南亞語言**，並整理出「你需要準備的文件」與「下一步該怎麼做」，另提供公文搜尋與多語詞彙查詢。

## 功能特色

- **公文白話翻譯**：貼上公文，AI 同時產出白話文翻譯、文件類型、應準備文件清單、下一步行動步驟與提醒。
- **10 種語言**：繁體中文白話、簡體中文、馬來語、印尼語、越南語、泰語、菲律賓語、緬甸語、高棉語、寮國語。
- **三種執行模式**：
  1. **Vercel 免費後端（AI）**：Groq 免費模型，翻譯、搜尋、查詞全部走 AI，品質最佳。
  2. **免費即時翻譯**：前端直接呼叫 Google 翻譯公開端點，不需金鑰、無 AI 額度限制，適合單純翻譯。
  3. **體驗模式**：離線示範，不需網路即可預覽介面。
- **公文搜尋**：輸入問題（例如「居留證什麼時候要延期」），AI 結合網路檢索與自身知識給白話答覆，並附官方入口。
- **詞彙小幫手**：針對公文術語提供 AI 白話解釋、例句與 9 語翻譯。
- **範例公文與歷史紀錄**：內建居留延期、健保加保、工作許可、新住民補助等範本；翻譯紀錄存於瀏覽器本地。
- **回應式設計**：桌面與手機皆可使用。

## 技術架構

- 前端：單一 `index.html`，原生 HTML / CSS / JavaScript，無建置流程。
- 後端：三個 Vercel Edge Function，API 金鑰只存在伺服器端，不暴露於瀏覽器：
  - `api/translate.js`：公文翻譯與結構化整理。
  - `api/search.js`：搜尋官方資料並由 AI 匯整答案。
  - `api/glossary.js`：術語白話解釋、例句與多語翻譯。
- AI 模型：預設使用 [Groq](https://groq.com) 免費額度（OpenAI 相容介面，模型 `qwen/qwen3.8-27b`，通義千問，中文表現佳）。
- 免費翻譯模式：Google 翻譯公開端點（僅翻譯，不經 AI 整理）。

## 本機使用

直接用瀏覽器開啟 `index.html`：
- 預設為「免費即時翻譯」模式，不需任何設定即可翻譯。
- 切換到「Vercel 免費後端」可使用完整 AI 功能；本機開啟時後端網址可留空，系統會自動改用已部署的線上 API。

## 自行部署（Vercel，免費）

1. 將本專案匯入 [Vercel](https://vercel.com)（連結 GitHub 倉庫即可於每次 push 自動部署）。
2. 於 Vercel 專案設定加入環境變數：
   - `LLM_API_KEY`：Groq API 金鑰（於 https://console.groq.com/keys 免費申請）。
   - （選用）`LLM_ENDPOINT`：OpenAI 相容的 chat completions 端點。
   - （選用）`MODEL_NAME`：模型名稱，預設 `qwen/qwen3.8-27b`。
3. 部署後前端以同源路徑 `/api/*` 呼叫後端。

## 免費額度提醒

Groq 免費方案有每分鐘與每日的呼叫次數／token 上限，適合個人使用、教學與示範；短時間大量使用可能短暫等待，頁面會顯示提示並可改用「免費即時翻譯」模式。
